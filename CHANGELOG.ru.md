# Изменения

[English](CHANGELOG.md)

## 0.2.0 — 2026-11-02

- Корпоративные IPv4/port-маршруты для LAN: независимый HTTPS/UDP fallback,
  приоритет точного порта, cooldown возврата и точный сброс соединений.
- Сохранение фактического outbound при scoped routing Apply; отдельные revisioned
  операции применения маршрутов, приоритетов серверов и настроек диагностики.
- Асинхронные HTTPS/STUN jobs, typed server references, ограниченный кэш
  завершённых результатов и ручная сортировка внутри исходных позиций групп.
- Единый procd observer и fenced recovery вместо cron-мониторинга VPN;
  аутентифицированная диагностика, cgroup v2 и nft socket изоляция.
- Разграничение read/write RPC, удаление исполняемого watchdog state, защита
  загрузок, временных файлов, процессов и установки на устройство.
- Компактный UI Dashboard/Servers/Settings и несколько подписок, ранее
  реализованные в локальной ветке разработки.
- Миграция ping на API v2; документация EN/RU о перезагрузке страницы, зависимостях,
  пользовательских сценариях, проверке безопасности и подготовке отката.

Это выпуск исходников; сборка пакета через OpenWrt SDK ещё не реализована.
Аппаратный бюджет 50 узлов, контролируемые LAN/flow-offload, cold boot и полная
приёмка установленного LuCI остаются открытыми. См. [проверку безопасности](docs/security-audit.ru.md)
и [процедуру приёмки](docs/routing-availability-acceptance.md).
