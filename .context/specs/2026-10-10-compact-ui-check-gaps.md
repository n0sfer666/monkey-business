# Компактный UI — почему проверки пропустили расхождения, и 4 замечания пользователя

Дата: 2026-10-10. Повод — ревью стенда пользователем после `make dev` (коммиты до `6b41d2e`).
Критерии — `2026-10-10-compact-ui-acceptance.md`, аудит — `2026-10-10-compact-ui-audit.md`.

## Сборка правильная

`make dev` собрал текущий `dev`. Dashboard в старом LuCI-виде, потому что итерация 4 (Dashboard)
не начиналась. Это записано в спеке (`2026-10-10-compact-ui.md`, «Дальше — итерация 4») и в аудите
(D1, blocker).

На скриншоте пользователя над Dashboard нет строки «Monkey Business · Dashboard · Servers ·
Settings». Стенд её отдаёт: снимок Playwright, 1280, `nav[aria-label="Monkey Business"]` есть.
Вероятная причина — браузер взял старый `dashboard.js` из кэша. Если строки нет и после
Cmd+Shift+R — это дефект.

## Почему проверки пропустили

### 1. Сбой в отчёте, а не в проверке: Dashboard, таблица подписок, сегменты фильтра
- Аудит нашёл эти расхождения:
  - D1 — Dashboard (blocker);
  - P1–P3 — колонки и перенос трафика;
  - S6 — сегменты;
  - X2 — «until».
- Исправлены только группы 2 и 6 и пункт X1 (спека `…-fix-overlays-tabs.md`).
- Группы 1, 3, 4, 5, 7 открыты, это около 30 расхождений.
- В задаче «попутные баги + `make dev`» я отдал стенд на проверку и не сказал первой строкой, что
  Dashboard ещё старый, а Servers и Settings расходятся с макетом по открытым группам. Ты
  проверял стенд как готовый.
- Механизм дыры:
  - у строк аудита нет статуса «открыто / закрыто в коммите X»;
  - отчёт о стенде не обязан сводить открытые расхождения.

### 2. Настоящая дыра в критериях: чекбокс Off
- Критерий А.1 требует сверять состояния из столбца «Состояния», а там только props борда.
- Варианты содержимого внутри борда в этот перечень не входят, поэтому сверять их было
  необязательно. Это, например:
  - строка off с отмеченным чекбоксом;
  - недоступный сервер;
  - ручной сервер с ✎;
  - hysteria ⊖;
  - бейджи active / reserve;
  - инлайн-редактор интервала с подсказкой.
- В VM во время аудита не было ни одного выключенного сервера. Вариант checked не
  воспроизводился, и это не попало даже в «Не проверено». Дыра осталась незамеченной.
- Стили я замерял (`getComputedStyle`) по списку элементов, который составлял сам. Чего нет в
  списке, того нет и в отчёте. Пары скриншотов сравнивал глазами, а чекбокс на 1280 занимает 14px.
- T5 нашёл неотмеченный чекбокс в Settings. Вывод «все чекбоксы нативные с `accent-color`» на
  остальные экраны я не распространил.

### 3. Данные в борде короче реальных
- В борде трафик — «[USED] / [TOTAL] GB · [DATE]», на стенде — «143.7 / 300.0 GB · until 2026-12-08».
- P2 перенос поймал, но критерии не требуют в целом сверять раскладку на реальных длинах данных.

### 4. `make dev` без проверки сетевой зависимости
- T2 проверял только «стенд поднимается». Прогон прошёл, потому что зеркала geo в тот момент
  отвечали.
- `make dev-down` удаляет VM вместе с geo-базами. Следующий `make dev` снова качает их из интернета.

## 4 замечания

1. **Dashboard не по макету.** Это D1, итерация 4 целиком: борды `Main` / `MobileDashboard`,
   модалки Routing / Geo.
2. **Чекбокс Off другого цвета** (Servers). В борде отмеченный — заливка warn (янтарная) с ×,
   неотмеченный — тёмный квадрат с рамкой. На стенде нативный `input` с
   `accent-color: var(--mb-accent)`, то есть синий с галкой. Это новая строка аудита S9; она
   связана с T5 (чекбоксы в Settings). Точный hex и размер — замером борда при исправлении.
3. **Geo-базы для dev-стенда — локальный кэш.**
   - Сейчас `deploy-vm.sh` при отсутствии баз в VM запускает `geo.sh download`. На свежем стенде
     это `curl` по зеркалам, у пользователя он упал по таймауту 120с (6–16 МБ из 16.5).
   - Требования пользователя:
     - качать один раз в папку проекта (gitignored); стенд кладёт базы в VM без интернета;
     - скрипт берёт файлы с первоисточника и сверяет хеш-суммы — так он решает, обновлять кэш
       или нет;
     - первичное наполнение — с живого R2S 192.168.1.1 (`/usr/share/xray/geoip.dat`,
       `geosite.dat`).
   - Детали (папка, источник сумм) — интервью при реализации.
   - **Сделано 2026-10-11:** `scripts/dev-geo.sh` + шаг `geo` в `make dev`. Кэш — `.dev-vm/cache/geo`
     (переживает `dev-down`), суммы — `.sha256sum` с зеркал `geo.sh`, сверка на каждом `make dev`
     (без сети — кэш как есть), пустой кэш — с R2S. В VM копируется только при разнице sha.
4. **Таблица подписок (Servers, 1280).**
   - Ширины колонок не как в борде: Name ~232px против ~114px, Traffic в 2 строки, кнопки
     Fetch / Ping / 🗑 прижаты к краю. Это P1–P3 и X2.
   - Жёлтая стрелка на сегментах All / VPNON (уточнение пользователя 2026-10-11): фильтр в борде —
     простой свитч. Активный сегмент — только тёмная заливка, без синего подчёркивания. У нас
     `kit/seg.js` рисует под активным синюю полосу (`inset 0 -2px 0 accent`) — её быть не должно.
     Это S6.

## Решения по критериям (интервью 2026-10-10)

Внесены в `2026-10-10-compact-ui-acceptance.md`.

- **Статус и сводка (Е.7–Е.8).**
  - В таблицах аудита колонка «Статус».
  - Любая передача стенда на проверку начинается со сводки открытых расхождений по экранам.
- **Инвентарь вариантов + фикстура (А.1).**
  - Варианты содержимого борда обязательны к сверке.
  - `make dev` получает режим засева фикстуры: сервер off, ручной, недоступный, вторая
    подписка. **Сделано 2026-10-11:** `make dev FIXTURE=1` (`scripts/fixture/`), плюс hysteria2 ⊖ и
    длинный трафик подписки для А.8. Недоступный — `127.0.0.1:9` в VM: Мак за R2S, TPROXY
    принимает TCP на любой внешний адрес, TEST-NET «отвечал».
- **Пиксельный diff + замер всех элементов (А.2).**
  - Пары «борд | реализация» прогоняются через diff с порогом.
  - Стили замеряются у всех элементов борда, сопоставленных по тексту и роли.
- **Реальные длины (А.8).** Перенос или сжатие на реальных данных стенда — расхождение M.
