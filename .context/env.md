# Переменные окружения (БЕЗ значений)

## Сборка/разработка (хост)
- `DOCKER_HOST` — если используется удалённый Docker (обычно не нужно).

## Dev-VM (scripts/dev-vm.sh)
- `MB_IMMORTALWRT_URL` — URL образа ImmortalWrt aarch64 для QEMU (переопределение дефолта).
- `MB_VM_SSH_PORT` — проброшенный SSH-порт dev-VM (дефолт в скрипте).

## Рантайм на роутере (этап 3+)
- Секреты (токен подписки VPNON, ключи Reality) хранятся в UCI с правами 0600,
  НЕ в переменных окружения, НЕ в репозитории, НЕ логируются.

## Загрузка файлов (fetch.sh, geo.sh, ruset.sh, hysteria.sh)
Дефолты в самих скриптах; переопределять нужно разве что при отладке на медленном канале.
- `MB_FETCH_TIMEOUT` — общий лимит на одну загрузку.
- `MB_FETCH_CONNECT` — лимит на установление соединения (быстро отсечь мёртвый хост).
- `MB_FETCH_MIN_RATE` / `MB_FETCH_STALL` — порог скорости и окно: ниже порога дольше окна зеркало
  бросается. Ловит зеркало, которое соединение приняло, но данные не отдаёт.
- `MB_FETCH_SOCKS`, `MB_FETCH_XRAY_MATCH` — адрес socks-фолбэка и cmdline боевого xray.
- `MB_HY_SUM_TIMEOUT` — отдельный, укороченный лимит на релизный `hashes.txt` (килобайты против
  21МБ бинаря).
- `MB_HY_MIRRORS`, `MB_HY_HASHES`, `MB_HY_BIN`, `MB_HY_STATE`, `MB_HY_CONF`, `MB_HY_LOCK` — пути и
  зеркала установщика hysteria (зеркала также читаются из UCI `monkey-business.hysteria.mirrors`).

## Подписка
- Реальная ссылка VPNON — у пользователя. В репозиторий/фикстуры НЕ коммитится.
  Для мока используется санитизированная фикстура (`scripts/capture-sub.sh`, этап 3).
