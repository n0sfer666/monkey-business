# 2026-06-09 — Публикация как open-source на GitHub

## Контекст
Проект планируется выложить в открытый доступ на GitHub.

## Решение
- Корневой `README.md` — **только на английском**, краткий и для внешнего читателя:
  описание проекта, как собрать пакет для установки, как поднять dev-окружение.
- Внутренняя документация (`.context/`, `.claude/`, dev-log) — остаётся как есть (RU), не для внешнего читателя.
- Перед первым публичным релизом: выбрать лицензию (сейчас TBD в README), проверить отсутствие
  секретов в истории git.

## Следствия
- Любые правки `README.md` держать на английском и в формате «для нового пользователя с GitHub».
- Не класть секреты/приватные пути в файлы, попадающие в репозиторий.
