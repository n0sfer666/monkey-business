# 2026-10-10 — LuCI-экраны на своём DOM, сервер только ссылкой

## Контекст
Компактный UI по макету (`specs/2026-10-10-compact-ui.md`): инлайн-поля подписки, плитки серверов
на мобилке, нижние шторки, ⋮-меню, единая разметка на десктоп и мобилку, тёмная/светлая тема.
CBI (`form.Map`, `GridSection`, `TypedSection`) этого не даёт без обходов, а обходы уже ломаются:
`MutationObserver` в `servers.js` после `Map.reset` смотрит на старый узел, sticky-шапка держится на
инлайн-`<style>`, валидация модалки сервера — на клонах опций (`cloneOptions`).

## Решение
**Все три экрана — свой DOM на `E()`**, без CBI. Половинчатый вариант (Settings на CBI) отвергнут:
два подхода в одном приложении и токены темы, которые на CBI-разметку целиком не ложатся.

**Модель изменений остаётся staged UCI LuCI** (`uci.set/add/remove/move`, `uci.save`,
`commit.apply` без rollback) — Save / Reset / Save & Apply и индикатор изменений ведут себя как
раньше, бэкенд и cron/watchdog не замечают смены фронта.

**Адаптив — CSS, а не две разметки.** Брейкпоинт 720px; модалка и шторка — один компонент.

**Тема — по `data-darkmode` темы bootstrap** (стоит на R2S), fallback `prefers-color-scheme`.

**Сервер задаётся только ссылкой.** Ручной ввод полей и Advanced из формы уходят; Edit есть только
у ручных серверов и работает через новую обратную сборку ссылки (`server_link`). Серверы подписки
не редактируются — Off / Delete. Строгая проверка ссылки (`parse_uri`, ADR 2026-08-07) остаётся
единственным валидатором; правила маршрутизации получают такой же метод `routing_check`.
Это частично заменяет ADR `2026-08-07-server-form-link-import.md`: переключатель «ручной ввод /
ссылка», `retain`, клоны опций и скрытое поле `encryption` больше не нужны.

## Последствия
- `serveropt.js` переводил секции с JSON-блоба на плоскую раскладку при сохранении формы. После его
  удаления миграцию делает запись ссылки (`parse_uri` → плоские поля + снятие блоба);
  `servermap.uc` по-прежнему читает оба формата.
- Сервер, который нельзя выразить ссылкой, через UI не завести — принято ради лаконичности.
- JS-логика без DOM выносится в `model/` и впервые покрывается node-тестами.
