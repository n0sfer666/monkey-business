# Конвенции

## ucode
- Модуль: объявить функции, в конце файла `export { a, b, ... };`.
  Инлайн `export function` НЕ поддерживается текущим ucode — не использовать.
- Импорт: `import { x } from "./rel/path.uc";` (пути относительно файла).
- Запуск: default-режим ucode = raw script (флаг `-R` не нужен).
- JSON: сериализация `sprintf("%J", v)` / pretty `%.J`; парсинг `json(str)`.
- Base64: `b64dec` / `b64enc`. Regex: `match(str, /re/)`, глобальный `/re/g` → массив матчей.
- `for (v in array)` итерирует **значения**, `for (k in object)` — **ключи**.
- Чистая логика (парсер/генератор) НЕ зависит от модулей `uci`/`ubus` — принимает обычные
  структуры на вход. Привязка к uci/ubus — только в rpcd-слое. Это держит логику host-тестируемой.
- Ошибки: `die("msg")` бросает; в rpcd-слое — возвращать `{ error: ... }`.

## Общие правила (из глобального CLAUDE.md)
- Без комментариев в коде, кроме явной необходимости/публичного контракта.
- DRY/KISS/SOLID. Файл ≤ 200 строк, иначе декомпозировать. Одна ответственность = один файл.
- Без `any`/type assertions (для типизированных частей — LuCI JS: избегать `any`).
- Импорты через относительные пути модулей ucode.

## Shell
- POSIX `sh` (не bash). `set -u`. shellcheck-чистый (`-x`).
- Цикл по `find` — через `while IFS= read -r` + here-doc, не `for in $(...)` (word-splitting).

## Именование
- ucode-файлы: `snake_case.uc`. Функции: `camelCase`. Константы: `UPPER_SNAKE`.
- UCI-секции/опции: `snake_case`.
