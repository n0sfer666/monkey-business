# Проверка безопасности и ограничения выпуска

[English](security-audit.md)

Обновление маршрутизации и доступности проверено вместе с остальным приложением,
включая прежние дефекты безопасности. Отчёт описывает проверенные границы,
а не гарантирует отсутствие всех уязвимостей.

## Изменения

- Scoped routing Apply сохраняет фактически применённый outbound и credentials.
  Проверки revision/runtime/network/intent отклоняют устаревшие мутации и recovery.
- Узкий transition guard защищает corporate proxy-направления при смене Xray/nft.
  Компенсация проверена вместе с сохранением результата повторяемого запроса.
- Единственный observer передаёт независимые HTTPS/UDP состояния маршрутизации
  и recovery. Незавершённый скан не заменяет завершённый результат новым timestamp.
- Аутентифицированные diagnostic listeners принудительно используют нужный VPN.
  Root-owned cgroup v2 и nft socket изолируют dynamic UDP relay до первого пакета.
- Reader RPC получает безопасные DTO; UCI, задания, загрузки и мутации требуют
  write-доступа. Старые ping RPC явно возвращают deprecated для API v2.
- Состояния, локи, логи и временные credentials защищены приватными каталогами.
  Исполняемое состояние старого watchdog удалено. Загрузки ограничены TLS,
  размером/временем и требуют полного ответа; устанавливаются проверенные байты.
- Deploy проверяет SSH host key, сохраняет существующую UCI и поддерживает
  BusyBox tar через файл исключений вместо GNU-only long options.

## Доказательства

Обязательные `make lint`, `make check`, `make test-unit` прошли. Интеграционные
проверки покрывают настоящий Xray config, TPROXY/DNS, изоляцию диагностики,
kill-switch, ошибки transition/rollback. Native rpcd/uhttpd проверяют ACL
reader/writer, API v2 и idempotency scoped order.

Одноразовый native OpenWrt-стенд проверяет procd/Xray/Hysteria/nft/UCI,
конкурентные LAN-запросы при reload и отказе Apply, устаревшие recovery decisions,
отмену, падение node process и очистку принадлежащих заданию процессов. Скан
50 VLESS-узлов с extra и cleanup занял 16,14 с; консервативная пиковая сумма RSS —
63 856 640 байт **в VM**.

На R2S три свежих раунда показали HTTPS/UDP up. Отдельный synthetic loopback-тест
заблокировал чужую инъекцию в Hysteria relay, сохранив root reply, посторонний UDP
и рабочий VPN listener. Процессы, группы и очередь после теста очищены.
Реальные корпоративные шлюзы не проверялись.

Локально квалифицированы OpenWrt 25.12.4/kernel 6.12.87, Xray 26.10.31,
Hysteria 2.13.0 и curl 8.23.0; device smoke-test также выполнен на ImmortalWrt
25.12.1/kernel 6.12.94. Произвольные будущие версии этим не квалифицированы.

## Открытая приёмка

Аппаратный бюджет 50 узлов, контролируемые LAN-пакетные пути и flow-offload,
cold boot, отказоустойчивость и полная установленная LuCI QA остаются открытыми.
Рабочий observer и замер VM их не заменяют. Обновление работающего VPN с сохранением
всех нужных proxy-путей не квалифицировано.

Общий LAN DROP не заменяет проверенный scoped guard. Перед установкой нужны
приватный backup и проверенный откат. Широкие сетевые блокировки требуют
отдельного явного согласования оператора.

Воспроизводимые проверки и оставшиеся требования — в
[процедуре приёмки](routing-availability-acceptance.md). Сборка пакета через
OpenWrt SDK ещё не реализована; тег исходников не означает готовый пакет.
